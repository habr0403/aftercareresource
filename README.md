# Minnesota Housing & Recovery Resource Navigator

A static, mobile-friendly website generated from `housing_FINAL_expanded.xlsm`.

## Open locally

Double-click `index.html`. The website uses no server and no external libraries.

## Deploy free

Upload the entire folder to any static host, including GitHub Pages, Netlify, Cloudflare Pages, or Vercel. Keep `index.html`, `styles.css`, `app.js`, and `data.js` together.

## Included features

- 309 searchable directory records
- Housing, residential treatment, IOP, recovery housing, reentry, and access-point categories
- Location, population, and needs filters
- Favorites and application/referral tracker saved in browser storage
- Side-by-side resource comparison
- CSV exports and print views
- Workbook guides, call scripts, checklists, definitions, housing profile, and 30-day plan
- Fully static; no personal information is uploaded

## Updating the data

The site data is stored in `data.js` and `data.json`. Regenerate those files after changing the workbook, or update the records directly while keeping the same object structure.

## Important notice

Availability, funding, eligibility, costs, insurance, licensed level of care, and referral requirements can change. Verify directly with each program before promising placement or paying an application fee.
